# 画布与脱敏检查约定

## 页面与连线

页面包含 `id`、`title`、`role` 和 `state`。连线包含 `from`、`to`、`kind` 和 `label`。`kind` 使用 `main`、`handoff`、`branch`、`return` 四种类型。图像清单由调用时提供的实际文件构成，示例JSON只描述节点和关系。

## 脱敏核对

覆盖系统标识、个人资料、内部链接和需要隐藏的业务字段。检查图片边缘、弹窗、表格、下载内容和元数据。处理原文件副本并保留内部映射，公开包采用中性文件名。

## 视觉与操作

按角色组织泳道，区分交接与分支。缩略图可读，放大后仍为已处理图像。测试平移、缩放、全览、节点打开与关闭、焦点恢复和窄屏操作。

## 静态发布

按站点子路径检查所有资源。固定发布文件清单和内容摘要，发布后回读关键页面和图片，确认线上与审阅版本一致。原型注明面试操作用途、数据处理范围及实际支持的功能。

本包采用通用业务名称与独立构造示例。公开内容仅展示方法、字段和校验过程，不包含真实组织、人员、客户、项目标识、内部地址、访问凭据或真实业务金额。
