# 岗位问题转交互培训课程

围绕真实学习问题编排目标、情景、动画与测验，保留事实来源、生成检查点及评分版本，支持局部修正与续作。

## 输入与开始条件

- 岗位问题、目标学员与已有基础
- 可引用知识材料及已确认的业务事实
- 学习目标、可观察的完成标准与预计学习时长
- 播放器可支持的交互组件、媒体资源与评分维度

先核对现有材料与本次交付目标。缺少会改变业务判断的依据时保留待确认项，其余可独立推进的部分继续完成。

## 执行流程

1. 把问题拆成可观察的能力目标，确认哪些事实已知、哪些需要核实。
2. 建立一致的教学情景，选择对照、分支访谈或事件时间线等合适形式。
3. 按目标编排讲解、练习、反馈与测验，并为每项内容绑定事实依据。
4. 生成结构化教学数据，检查对象引用、正确选项、反馈依据与维度覆盖。
5. 使用受控播放器呈现场景，按实际音频时间安排重点与暂停练习。
6. 分步保存合格产物，输入变化时使依赖步骤失效，修正后从未完成步骤续作。

## 关键判断

- 演示情景和业务事实分别标注，承诺、金额或业绩需要材料依据。
- 题目与评分标准在提交前冻结并记录版本，评分和作答证据一同保存。
- 课堂练习与正式测验采用各自的记录口径。
- 模型输出采用受控数据结构，渲染器仅执行可信组件。

## 交付与验收

- 学习目标、教学情景与分段课程数据
- 交互练习、针对性反馈与测验评分说明
- 媒体与内容检查记录、步骤依赖及续作信息

- 每道题、每段讲解都能关联到目标与事实。
- 正确选项、权重、引用和交互类型通过结构检查。
- 实际播放验证暂停、跳转、声音、练习反馈及窄屏布局。

## 参考与示例

- 需要字段、评分或版本细则时读取 [执行约定](references/guide.md)。
- 使用 [独立构造示例](assets/example.json) 理解输入结构，按当前任务提供的资料与配置执行。
- 运行 `python3 scripts/check_course.py assets/example.json` 检查样例的目标、事实、题目与评分结构。

## 公开数据说明

本包采用通用业务名称与独立构造示例。公开内容仅展示方法、字段和校验过程，不包含真实组织、人员、客户、项目标识、内部地址、访问凭据或真实业务金额。
