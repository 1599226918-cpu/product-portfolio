# 工程项目宣传片制作

从素材与项目事实出发，把项目背景、重点问题、团队行动和交付价值编排为可制作、可返修、可核验的视听内容。

## 输入与开始条件

- 项目介绍、目标受众与传播目的
- 获准使用的实拍、图纸、效果图和人物素材
- 时长、画幅、字幕、配音及品牌要求
- 参考片、当前版本和本轮明确反馈

先核对现有材料与本次交付目标。缺少会改变业务判断的依据时保留待确认项，其余可独立推进的部分继续完成。

## 执行流程

1. 核对素材来源与项目事实，建立主题、证据和待确认项。
2. 按受众组织项目背景、任务难点、团队行动与可证实结果。
3. 将叙事拆成包含信息目的、动作、景别、运镜、字幕与声音的分镜。
4. 先生成可审阅的关键画面和样段，按确认范围继续制作。
5. 根据实际配音长度安排镜头与字幕，处理接缝、人物一致性和画面清晰度。
6. 检查实际导出视频，记录视听问题与局部返修，并交付可追溯版本。

## 关键判断

- 实拍、效果图与生成画面分别记录，陈述与素材依据对应。
- 人物动作与工艺过程应符合场景，参考片转化为可观察的镜头与节奏要求。
- 局部返修明确镜头、区域和保留版本，避免扩大修改范围。
- 编码解码、音画检查、用户审片与最终确认分别记录。

## 交付与验收

- 叙事大纲、素材来源表与可执行分镜
- 样段、审片视频及字幕或旁白文件
- 返修记录、导出参数与实际视听检查说明

- 关键画面与陈述均有素材或确认依据。
- 旁白、字幕、人物动作和画面重点相互对应。
- 实际成片经过连续播放、接缝、清晰度及媒体规格检查。
