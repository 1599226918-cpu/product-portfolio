# 权限矩阵与证据约定

## 矩阵字段

记录 `role`、`resource_scope`、`action`、`expected`、`rule_source`。用例另外记录主体、资源、前置授权、变更动作、预期结果、实际结果及证据。

## 需要确认的优先级

确认角色基础权限、项目或部门范围、单资源授权及独立管理员身份如何共同决定结果。三档阅读、下载、编辑是样例模型，实际项目按输入规则建立角色。

## 回归场景

- 阅读可见与原件下载分别测试。
- 编辑、审批、成员管理分别校验。
- 成员降级、移除与资源转移后检查旧授权。
- 直接URL、旧消息卡片和缓存页面重新访问。
- 检查其他角色及不相关资源的权限是否受影响。

## 结果记录

每条用例记录预期、实际和证据。通过结论应注明界面、接口或其他验证层。无法使用相应身份检查的用例标为待验证，并说明缺少的条件。

本包采用通用业务名称与独立构造示例。公开内容仅展示方法、字段和校验过程，不包含真实组织、人员、客户、项目标识、内部地址、访问凭据或真实业务金额。
