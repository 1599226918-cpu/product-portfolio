# 动画交互工作流

作品集公开说明版，整理自本地 animejs Skill。

## 适用场景

网页、SVG 与 JavaScript 对象动画：入场、错峰、路径描边、悬停反馈、组件动画与多元素时间线。

## 工作步骤

1. 检查现有框架、Anime.js 版本和动画入口，沿用项目约定。
2. 列明目标元素、初态、终态、时长与触发条件。
3. 编排动画时间线，将选择器和动画范围限制在所属组件。
4. 处理重播、组件卸载、事件清理与减少动态效果模式。
5. 需要离线逐帧输出时，以确定的帧时间驱动动画。
6. 在实际浏览器中检查初态、中间态、终态、重播和窄屏表现。

## 交付

可编辑代码、预览入口与实际完成的验证记录。导出视频需要另外检查输出文件；仅能导入代码不代表界面动画正确。
