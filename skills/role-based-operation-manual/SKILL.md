# 多角色操作手册生成

将角色职责、页面证据和业务状态组织成任务导向手册，覆盖操作步骤、交接结果、异常处理与版本核对。

## 输入与开始条件

- 目标读者、角色责任与可操作范围
- 已核实的业务流程及状态说明
- 获准使用的对应页面截图和字段说明
- 目标文档格式、终端、版本与验收要求

先核对现有材料与本次交付目标。缺少会改变业务判断的依据时保留待确认项，其余可独立推进的部分继续完成。

## 执行流程

1. 按角色建立任务目录，说明各角色的入口、目标和交接对象。
2. 把每项任务拆成操作前提、执行步骤、成功表现与完成条件。
3. 为步骤绑定页面证据，核对截图、字段和按钮与目标版本一致。
4. 补齐退回、撤回、异常恢复、无权限和空数据等必要场景。
5. 生成总流程与角色分册，统一术语、截图编号及跨册引用。
6. 实际渲染并检查字号、分页、截图清晰度和关键步骤，记录待补证据与交付版本。

## 关键判断

- 按角色可见和可操作范围编写，查看权限与处理权限分别说明。
- 步骤说明应写出实际操作结果和下一位责任人。
- 截图、原型设计和计划功能分别标明依据状态。
- 文档按目标终端检查，修改后复核受影响章节和引用。

## 交付与验收

- 总流程、角色任务索引与分册手册
- 步骤和截图对应表、异常处理说明
- 版本变更、渲染检查与交付核对记录

- 关键任务有操作前提、步骤、结果与完成条件。
- 角色间交接在相关分册中一致。
- 关键页面可读、编号一致、交付文件可打开。
